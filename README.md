# 月見坂ナイトラン

実在の車と世界のサーキットを走る、ブラウザ用の3Dレースゲーム。

- 遊ぶ: https://tsukimizaka-night-run.netlify.app
- ゲーム本体: `site/`（`main` に push すると Netlify が自動で公開）
- 開発の手順: [CLAUDE.md](CLAUDE.md)（車・コースの追加、検査、テスト）
- テスト: `node tests/run.js`

3Dモデルはすべて Sketchfab の作品を軽量化して使っています。作者とライセンスはゲームのタイトル画面「3Dモデルのクレジット」と各車・コースの説明に記載しています。
