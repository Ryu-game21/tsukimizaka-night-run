箱根ターンパイク（Unity 試作・見た目強化版）

【準備（最初の1回）】
1. 車のモデルを読むための公式パッケージを入れる:
   Window → Package Management → Package Manager → 左上の「＋」→「Install package by name...」
   → com.unity.cloud.gltfast と入力して Install
2. （おすすめ）地面と草の写真素材: Asset Store の「Terrain Sample Asset Pack」（Unity Technologies・無料）を
   「マイアセットに追加」→ Package Manager の「My Assets」から Download → Import
3. （あれば）木の素材: 針葉樹（pine / fir / conifer など）の無料パックを同じように Import
   ※ 2 と 3 がなくても動きます（スクリプトで作った素材で代わりに作ります）

【使い方】
1. この「Turnpike」フォルダを Project 欄の Assets にドラッグ（前の版があれば置き換え）
2. メニューの「Turnpike」→「シーンを作る (Build Scene)」（数分かかります）
   Console に「地面の素材」「木の素材」「草の素材」と出た物が使われています
3. ▶ で再生

【操作】
W/↑ アクセル　S/↓ ブレーキ（止まっていればバック）　A/D または ←/→ ハンドル
Space サイドブレーキ　C 視点切り替え　R スタートへ戻る　（ゲームパッドも可）
